# Introdução à Programação para Dispositivos Móveis 📱

Repositório destinado às atividades e projetos da disciplina de Programação Mobile, ministrada pelo professor Rodrigo Grassi Martins no IFTM. Este projeto foi configurado utilizando o Expo com JavaScript puro.

## 🚀 Como rodar o projeto

Se for a primeira vez baixando o projeto, instale as dependências:
```bash
npm install

npx expo start

git add .
git commit -m "Descreva o que foi feito na aula de hoje"
git push origin main

📦 Comandos do Expo (Criação e Testes)

npx create-expo-app nome-da-pasta --template blank

cd nome-da-pasta

npx expo install react-dom react-native-web

npx expo start

tecla w

Comandos do Git (Configuração Inicial do Computador)

git config --global user.name "Seu Nome"

git config --global user.email "seu@email.com"

Comandos do Git (Rotina de Salvar e Enviar)

git add .

git commit -m "Mensagem aqui"

git push origin main

git push -f origin main
